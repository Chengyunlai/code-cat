# 从一段解释走到真实源码

打开 [TS / JS 库存示例](../../stage-02-node-conversation/user_code/README.md)，配置支持流式响应的模型，提问：“这个项目做了什么？请带我从最小入口理解库存判断。”

1. 模型返回正文片段时，对话开始显示回答，无需等待整段完成。
2. 解释应先回答问题，再用短标题、阅读顺序和小段代码展开，避免在一段话里堆所有符号。
3. 点击形如 `[库存判断](main.ts:2)` 的源码引用，在编辑器中核对；链接打开当前工作区文件，并不代表历史文件未改变。
4. 代码块保留换行和基础高亮，可复制。代码示例与真实源码须根据正文标注区分。
5. 在断点处问“这个判断依赖哪些值？”，单步验证，再继续追问。
6. 生成期间可以编辑下一条问题，或点击“停止回答”。中断或格式错误显示失败提示并允许重试，未完成内容不写入历史。

实际表达仍受模型影响。源码跳转会验证工作区路径与行号；模型输出不能执行命令或打开任意外部地址。

历史操作：得到两条不同的路径回答后，滚回第一条。点击源码核对，再点击“用断点跟一遍”；运行中显示“在这里打断点”，不会替换当前路径。结束后或重开会话，入口仍然保留。
